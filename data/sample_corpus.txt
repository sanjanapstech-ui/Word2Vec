Machine learning is a field of study that gives computers the ability to learn patterns from data without being explicitly programmed for every rule. A machine learning algorithm builds a model based on sample data known as training data in order to make predictions or decisions.

Natural language processing is a branch of artificial intelligence concerned with the interaction between computers and human language. Common natural language processing tasks include text classification machine translation question answering and sentiment analysis.

A neural network is a computational model made of layers of connected units called neurons. Each neuron receives input performs a simple calculation and passes an output forward to the next layer. Deep learning refers to neural networks with many layers stacked together.

A word embedding is a dense vector representation of a word that captures its meaning based on the words that tend to appear around it. Words that share similar contexts end up with similar vectors. For example the words king and queen tend to appear near similar words such as throne crown palace and royal.

Word2vec is a technique for learning word embeddings from a large amount of text. It slides a window across a sentence and trains a simple model to predict which words tend to appear near a given word. The skip gram variant takes a single word as input and tries to predict its neighboring context words. The continuous bag of words variant does the opposite by using the surrounding context words to predict the center word.

Negative sampling makes training a word embedding model much faster. Instead of comparing a word against every other word in the vocabulary the model only compares it against a small number of randomly chosen negative words. This turns an expensive multi class prediction problem into a cheap binary classification problem.

Cosine similarity is a common way to measure how similar two vectors are by looking at the angle between them rather than their length. Vectors pointing in a similar direction receive a high cosine similarity score even if their magnitude is different.

Word embeddings can capture surprising relationships. The vector arithmetic king minus man plus woman often lands close to the vector for queen. This happens because the model learns that the difference between king and man captures a notion of gender and royalty that transfers to other word pairs.

Recurrent neural networks and transformers are two families of neural network architectures used to process sequences of text. Transformers rely on an attention mechanism that allows the model to weigh the importance of every other word in a sentence when processing a given word. This attention mechanism removed the need for the step by step processing that recurrent neural networks required.

Retrieval augmented generation combines a large language model with an external knowledge base. A query is converted into a vector using an embedding model and then compared against vectors stored in a vector database to find the most relevant pieces of context. That retrieved context is passed to the language model along with the original question so the model can generate a more accurate and up to date answer.
